# 🚀 Manu M.R — Personal Portfolio

> A modern, responsive personal portfolio website designed and developed from scratch using HTML, CSS, and Vanilla JavaScript.

## 🌐 About The Project

This is my personal portfolio website created to showcase my journey as a Computer Science Engineering student, my technical skills, projects, and interest in web development and technology.

The website focuses on a clean, premium, and interactive user experience without relying on frameworks or libraries.

---

## ✨ Features

- 🎬 Animated loading screen
- 🖥️ Modern dark-themed interface
- 🌙 Dark / Light mode
- 📱 Fully responsive design
- 🧭 Sticky navigation bar
- 🔗 Smooth scrolling navigation
- ✨ Scroll-triggered animations
- 💻 Interactive hero section
- 👨‍💻 About Me section
- 🛠️ Animated skills section
- 🚀 Project showcase
- 📩 Contact form with JavaScript validation
- 📱 Responsive mobile navigation
- 🎨 Modern hover and transition effects
- ⚡ Built without frameworks or libraries
